MediQueue – Healthcare Appointment System

MediQueue is a Django web application developed as a Full Stack project at AXSOS Academy.

Features

Patient registration and login

Search doctors by specialty

Book, cancel, and reschedule appointments

Doctor dashboard

Patient insurance information

AI Assistant using AJAX

Technologies

Python, Django, SQLite, HTML, CSS, Bootstrap, JavaScript, AJAX, and scikit-learn.
